# Codex Project Instructions

Project: SmartRetireNL MVP

## Goal
Build an MVP for a Dutch retirement planning platform that includes:
- personalized profiling
- Monte Carlo simulation
- simplified Dutch pension/tax logic
- scenario comparison
- AI-generated explanation layer

## Constraints
- The AI explanation layer may explain outputs, but should not independently create financial advice logic.
- Keep the architecture modular and easy to demo.
- Prefer simple, transparent Python code over overly complex implementation.

## Coding Style
- Write modular functions
- Use clear variable names
- Add concise comments where helpful
- Keep files small and readable

## Priorities
1. Working MVP
2. Clear architecture
3. Clean repository
4. Easy demoability

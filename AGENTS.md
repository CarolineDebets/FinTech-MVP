 # AI Agents Used

This project uses Codex as the default coding agent.

## Why Codex
Codex was chosen because it supports rapid prototyping, code generation, repository-wide editing, and structured software development workflows.

## How we use Codex
- Generate boilerplate and module scaffolding
- Refactor code into cleaner architecture
- Help document the project
- Support testing and debugging

## Human oversight
All generated outputs are reviewed, edited, and validated by the team before inclusion in the final MVP.

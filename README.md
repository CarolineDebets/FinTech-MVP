 # SmartRetireNL MVP

SmartRetireNL is an AI-powered retirement planning MVP for Dutch households.

This prototype helps users explore retirement outcomes using Monte Carlo simulation, simplified Dutch pension/tax rules, and AI-generated explanations in accessible Dutch.

## MVP Features
- Personalized financial profiling
- Monte Carlo retirement projection
- Simplified Dutch tax/pension signals
- Scenario comparison
- AI-generated Dutch action plan

## Tech Stack
- Python
- Streamlit
- NumPy / Pandas
- Plotly

## Project Structure
- `app.py` – main application entry point
- `src/` – business logic modules
- `tests/` – test files
- `docs/` – architecture and assignment documentation
- `.codex/` – Codex agent instructions
